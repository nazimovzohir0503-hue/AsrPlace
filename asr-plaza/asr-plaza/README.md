# ASR Plaza — restoran sayti (shablon)

Ochish: VS Code -> File -> Open Folder -> asr-plaza. "Live Server" kengaytmasi bilan index.html ni ishga tushiring.

Tuzilma:
- index.html      — sahifa tuzilmasi
- css/style.css   — dizayn (ranglar va shriftlar tepada :root ichida)
- js/data.js      — BARCHA ma'lumot: telefon, manzil, ish vaqti, menyu, uch tilli matnlar
- js/main.js      — mantiq (til almashtirish, menyu, "hozir ochiq", bron formasi)
- images/         — rasmlar uchun (keyingi bosqich)

Birinchi qadam: js/data.js dagi TODO belgili joylarni haqiqiy ma'lumot bilan almashtiring.
